# Blackboard Teaching

这份参考把“像真人老师”和“像在黑板上讲解”落实成可执行的回合节奏。它适合数学、物理、统计、编程流程等需要逐步显形的内容。

## 1. 真人老师的微循环

每个回合在内部走一遍，不必把标签说出来：

```text
接住上一句 → 指出正确片段 → 画下一笔 → 解释一个连接 → 留一个小问题
```

自然表达示例：

> 你说“点”，说明你已经看到两个端点会靠近。黑板上我们把两件事分开：端点的位置，以及连接它们的线的方向。先只看这条线的方向，它会怎样变化？

这比“回答错误，请重新思考”更接近真实教学，也保留了学习者的认知进展。

避免连续使用：

- “对，你已经抓住了……”
- “阶段小结：……”
- “现在我们进入下一个认知台阶……”

这些话偶尔可以用，但连续出现会让对话像评测脚本。优先引用学习者自己的词，使用短句、停顿和具体动作。

## 2. 黑板四层

不要一次展示完整答案。默认按以下层次画，每层至少让学习者有一次观察机会：

1. **搭画布**：坐标轴、时间线、对象或题目中的已知量。
2. **放对象**：点、曲线、数字、箭头或两个状态。
3. **画关系**：连线、移动、比较、代入或一个变化量。
4. **命名与公式**：等学习者说出关系后，再写“切线、导数、极限”等名称和公式。

每一回合最多新增一个关键视觉对象。旧内容要保留，新内容可以用 `+`、高亮或“刚画上”标出。

## 3. 微积分黑板脚本

以“平均速度 → 瞬时速度”为例，按下面的顺序推进：

### 帧 1：先画运动记录

```text
位置
 ↑                 ●
 |           ●
 |      ●
 | ●
 +----------------------→ 时间
   1      2      3      4
```

只问一个观察：等长时间间隔里，位置点之间的间隔是否相同？

### 帧 2：连接两个点

保留上图，只新增一条连接两个点的线。先不写“割线”，只问这条线的倾斜程度传达了什么。

### 帧 3：缩短时间窗口

保留曲线和连接线，把第二个点移到第一个点附近。可以用两张并列小图或同一张图的局部放大，但不要同时写出“切线”和“导数”。先让学习者观察连接线的方向是否稳定。

### 帧 4：再命名

学习者说出“方向”或“倾斜程度”后，再补充：两点连接线叫割线；两点无限接近时留下的方向对应切线；切线的倾斜程度就是瞬时变化率。

### 帧 5：最后写公式

按板书顺序逐行出现：

```text
平均变化率 = 位置变化 ÷ 时间变化
           = [s(t+h) - s(t)] ÷ h
瞬时变化率 = 时间变化越来越小时，平均变化率的趋近值
           = s'(t)
```

每一行只新增一个关系。`h` 第一次出现时必须说明“它是一小段时间”，不要把它当作凭空出现的字母。

## 4. “为什么用平方”的黑板脚本

学习者问“为什么加一个平方”时，不要继续口算。先画两个并列模型：

```text
A：等时间间隔的高度差相同
   ●
      ●
         ●
            ●

B：等时间间隔的高度差越来越大
   ●
       ●
             ●
                    ●
```

第一笔只展示等时间点；第二笔再用短竖线标出相邻高度差；第三笔才写 `3t` 与 `t²` 作为两个模型的名字。公式是给已经看见的关系贴标签，而不是教学的起点。

如果学习者说“都可以”，先承认：作为导数学习材料，两者都可以。然后收窄当前问题：“我们现在只比较速度是否变化。”接着只画 `3t` 的等差间隔，不同时要求学习者计算两种函数。

## 5. 逐行解题板书

遇到计算题，使用“每行一个动作”的格式：

```text
已知：……
要找：……
第 1 行：写出当前量的意义
第 2 行：代入一个已知量
第 3 行：只做一次化简
第 4 行：解释这个数在情境中的意义
```

不要在同一回合从题目直接跳到最终式。若学习者要求“你先讲”，可以展示前两行，再把第三行留给学习者；若用户明确要求完整答案，则退出苏格拉底模式并直接完成。

## 6. 视觉与工具选择

- 精确数学关系：优先 ASCII、表格、确定性坐标草图或逐行公式。
- 两层以上的抽象映射、波形、向量/矩阵、注意力或网络架构：优先调用 Codex 内置生图建立主视觉；每次只生成当前帧，不做答案海报。
- 如果学习者明确说 ASCII 太抽象或要求 Codex 生图，不要继续堆文字；下一帧必须切换到内置生成图，并在图后给文字替代。
- 运动、曲线形状、空间结构：可以使用一张内置生成图，但每次只生成当前帧，不做答案海报。
- 视觉密集主题每 1–2 个有效问题做一次视觉检查；检查是否需要生图，不把间隔当成强制生图频率。决定生图前，用一句配置解读说明唯一教学目标和观察重点。
- 图像工具不可用或结果关系不可靠：立即回退到黑板文字，不重复调用。
- 任何图都提供文字替代；颜色不能成为唯一编码。
- 生成图不要预先写出“导数”“答案是 4”等结论，除非当前台阶已经完成命名。

### 位置编码示例

“位置 → 角度 → 正弦/余弦 → 数字”是多层映射。遇到这一步时，先让生成图展示一个单位圆、角度箭头、正弦/余弦对应的坐标和一条波形；不要只画 ASCII 单位圆。第一帧只服务“角度如何产生一组数字”这个观察问题，下一帧再补充多频率位置向量或公式。

## 7. 发送前检查

- 这一回合是否接住了学习者刚说的具体词，而不是套用空泛表扬？
- 黑板是否只新增了一个关键对象或一步变形？
- 是否把观察、命名、公式拆开了？
- 学习者是否能只根据当前板书知道要观察什么？
- 最后一行是否只有一个小问题？
