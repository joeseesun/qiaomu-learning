# Self-Contained Web Learning

网页模式把 qiaomu-learning 的学习协议装进一个可操作的学习容器。它不是另一个内容生成器，也不是把长答案排版成网页；它必须让学习者观察、选择、操作、回答，并能回到对话继续得到自适应教学。

## 1. Routing gate

进入网页模式需要学习者明确提出网页/网站/互动学习页/学习工坊，或在已有学习对话中明确要求把内容转成网页。只有“带我学”“一页页讲”时，保持对话模式。

网页模式适合：

- 一个概念需要拖动、切换条件或观察输入—输出变化；
- 一个主题需要 12 词地图、章节导航、闪卡和复习进度；
- 一份 PDF/课程需要保留页码、章节、错题和待迁移问题；
- 学习者希望离线反复练习，且内容边界已经足够稳定。

网页模式不适合：

- 一句定义、快速解释或单次问答；
- 当前材料尚未读清、来源冲突尚未处理；
- 主要价值来自老师根据自然语言实时判断，而不是固定选项或可见操作；
- 用户没有授权写文件、保存进度或把材料放进网页。

## 2. Minimal artifact selection

| 目标 | 选择 | 必须包含 |
|---|---|---|
| 看见一个关系 | 概念小实验 | 一个可观察控件或图、一个问题、一个文字替代 |
| 学完整个主题 | 主题学习工作台 | 12 词地图、当前台阶、问题分支、闪卡或进度 |
| 复习材料 | 课程复习册 | 章节/页码锚点、复习卡、待复习项、迁移题 |

选择能承载目标的最小页面。不要默认生成首页、索引、进度、详情等一整套站点，也不要为了视觉效果加入无关动画。

## 3. Self-contained implementation

默认交付一个 `.html` 文件：HTML、CSS 和 JavaScript 内联；不加载 CDN、远程字体、外部图片、第三方脚本、遥测、账号系统或默认部署服务。若用户明确要求多个文件，也先保持依赖最少，并说明文件之间的关系。

页面必须：

- 在桌面和手机宽度下可读，不需要横向滚动；
- 支持键盘焦点、按钮语义和可见状态；
- 不把颜色作为唯一信息，图示有文字替代；
- 当前只展示一个认知台阶和一个问题；答案提交后只推进一个分支；
- 将“正确”“部分正确”“错误”“卡住”的预设反馈写成可检查的分支，而不是伪装成实时个性化模型；
- 使用本地存储时明示数据只保存在本机，并提供清除进度入口；
- 对来源材料保留页码/章节/定位线索，区分类比、补充背景和未知。

如果页面中有交互图，图负责呈现关系，文字负责精确说明；如果数值、坐标或因果方向很重要，优先用确定性 HTML/SVG/Canvas 或表格，不让生成图承担精确计算。

## 4. Dialogue and webpage division of labor

| 工作 | 对话 | 网页 |
|---|---|---|
| 诊断已有理解 | 负责 | 不假装实时诊断 |
| 解释为什么答错 | 负责 | 提供有限提示和分支 |
| 观察结构关系 | 引导 | 承载图、控件和实验 |
| 重复记忆 | 安排 | 闪卡、复习队列 |
| 新情境迁移 | 出题与判断 | 提供迁移题入口 |
| 进度记录 | 默认不持久化 | 用户同意后本机保存 |

页面上的问题仍遵守“一轮一个问题”。对话接回网页结果时，不把“点了按钮”当成已经理解；仍需学习者用自己的话解释，并在新情境中迁移。

## 5. Generation and audit handoff

生成前给一句面向学习者的配置解读：

> 这页只帮助你观察 `<关系>`；它包含 `<控件/图/问题>`，暂不直接展示 `<答案或后续结论>`。

生成后检查：

1. 页面是否自包含，离线打开是否不依赖网络；
2. 桌面/移动端是否溢出、遮挡或出现过小点击区域；
3. 当前问题是否只有一个，答案是否被页面文案、颜色、进度或图示泄露；
4. 图示、颜色、动画是否有等价文字路径；
5. 预设反馈是否与来源和当前台阶一致；
6. 若保存进度，是否有隐私说明和清除入口；
7. 是否明确交付状态：已生成本地文件、仅给出 HTML 内容，或已部署（只有真实验证后才能说已部署）。

可先运行包内的静态检查：

```bash
python3 scripts/audit_webpage.py ./learning.html
```

它会拒绝远程 `src/href`、外部脚本、iframe、缺少 viewport 或 title 的页面；如果页面使用本机存储，还会要求本机保存说明和清除入口。它不声称完成浏览器渲染或真实学习体验验收。

网页生成失败或宿主不能写文件时，退回到确定性黑板、表格、ASCII 或可保存的 HTML 文本；不重复盲试，不声称已经创建、运行或部署。

## 6. No false adaptation

静态网页只能执行预先设计的分支。它可以根据选择显示下一步，但不能声称理解了开放式自然语言回答，除非宿主实际把回答交给对话模型并返回可验证结果。开放回答优先回到 qiaomu-learning 对话，由老师根据回答重新选择认知台阶。
