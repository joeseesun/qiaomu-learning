# 为理解制作定制产物

## 选择目标与形态

模型承担越来越多的基础工作时，学习者仍需要看懂结果、检查假设、识别边界和判断下一步。不要只把模型答案写得更长；把难理解的关系转换成学习者能观察、操作或暂停检查的产物。定制网页、实验和解释视频可以只用一次，不必为一次学习建设长期软件。

| 理解任务 | 优先形态 | 学习者的动作 |
|---|---|---|
| 定义、适用条件、精确结论 | 清晰文字 | 用自己的话区分条件与结论 |
| 比较、结构、因果、空间关系 | 表格或图解 | 指出差异、路径或方向 |
| 改变输入、观察输出、检验假设 | 自包含 HTML 实验 | 先预测，再调一个变量 |
| 连续变化、运动、推导过程 | 动画解释视频 | 在关键帧暂停，预测下一步 |

先确定一个理解目标、已知基础和真实卡点。能从材料和当前对话推断就直接使用；必要时只问一个缺失信息。可主动建议“这个关系适合做成可拖动的实验”，不要空泛列出工具菜单，也不要默认制作全部四种形式。多形式可以互补：短文给精确定义，图解展示结构，网页检验假设，视频展示连续变化。

## STE 启发的清晰写作

ASD-STE100 是面向英文技术文档的受控语言，包含写作规则与受控词典。这里借鉴它降低歧义的原则，不复制完整规范，也不把中文解释称为合规 STE。

- 一句一个主要关系；需要表达条件、动作和结果时，按因果顺序拆开。
- 写出主语和动作，少用“进行处理”“相关机制”等空泛名词；技术术语首次出现先定义，之后用同一个名称。
- 用熟悉词、主动语态和明确指代；保留必要条件、例外、单位与不确定性，不为短句删掉逻辑。
- 解释当前一步即可；沿用同一个具体例子，不用换一串比喻掩盖缺失的因果连接。
- 用户说“80% STE”时，保持短句与稳定术语，允许自然中文、必要类比和老师语气。“80%”不是可测量合规等级。
- 用户要求严格英文 STE 时，以可访问的正式规范和词典逐项检查；模型自称熟练不能替代检查。未核验时称“STE 启发的草稿”。

示例：把“输入扰动通过参数敏感性机制影响最终输出”改成“先只改变一个输入。保持其他输入不变。观察输出怎样变化。”实际教学仍只保留当前问题需要的句子，不提前给出待推导结论。

官方来源：[ASD-STE100 简介](https://www.asd-ste100.org/about.html)、[官方 FAQ](https://www.asd-ste100.org/faq.html)。具体合规工作需核验当时适用的规范，不把这里的教学建议冒充完整标准。

## 图解与 HTML 实验

图解沿用 `visual-expression.md`：按信息形态选择最小视图，复核方向、标签、数量和数值，提供等价文字。精确数学关系用 SVG、Canvas、绘图代码或表格，生成图用于直觉场景。

网页沿用 `web-learning.md`。明确要求“HTML 格式”“做一个互动学习页”即已授权创建必要本地文件，不再重复确认；普通对话中可先提出一个具体实验，得到同意后制作。默认一个离线、自包含 HTML 文件，不部署、不上传材料。

一个实验围绕“预测 → 操作一个变量 → 观察 → 解释”设计。先隐藏答案和未来结论；操作后只推进当前分支。动画须可暂停或逐步播放，并支持减少动态效果。当前图形旁提供含义、单位和文字替代。用户只要求完整解释型产物时可以展示完整结论，不把苏格拉底式隐藏答案强加给直接交付。

## 定制解释视频

仅在明确视频请求或同意具体视频方案后制作。若用户指定 3b1b 风格，提炼为“几何直觉、图形与符号同步、保留前一帧、逐步变形、用具体例子建立抽象关系”；不复制原视频、旁白、品牌或虚构其作者参与。

1. **教学分镜**：从当前卡点出发，列出学习目标、假设、具体例子和关键帧。每段只解释一个关系；新符号首次出现就定义。完整视频将台阶串联，短片段只覆盖当前台阶。
2. **画面与旁白**：旁白描述当前可见变化，图形与符号同步出现；关键推导保留观察时间，设置可暂停的预测点。字幕与完整文字稿提供无声和无视频路径，旁白采用上面的清晰写作原则。
3. **执行路径**：优先使用已安装且可用的动画、渲染和 TTS 工具；需要专门视频技能时按其说明执行，不把某一供应商设为必需依赖。API 文档、服务能力和费用不确定时核验。ElevenLabs 可作为已配置选项；无密钥时先检查可用本地 TTS 或免费路径，说明质量取舍，不要求用户在聊天中粘贴密钥。
4. **权限与成本**：制作请求授权必要的本地脚本、动画、音频与渲染文件；外部服务、材料上传或新增费用按已有授权处理，缺少必要授权时只询问该缺口，继续可独立完成的分镜与画面工作。不擅自注册服务、购买额度或安装大体积运行环境。
5. **验收与交付**：实际渲染后检查文件可解码、时长、关键帧、公式和箭头、旁白音轨、字幕同步与可读性，抽查开头、推导转折和结尾；可播放预览时检查播放。交付真实视频文件、字幕和文字稿，按需保留可编辑源文件。网页动画不能冒充导出视频，脚本或分镜不能冒充成片；未完成的部分明确标注。
6. **失败降级**：缺少渲染或 TTS 能力时，交付已完成的可暂停 HTML 动画、无旁白视频或分镜与文字稿，并明确缺少什么。不要把生成成功或观看完成当成掌握证据；回到对话时，按学习者意愿只问一个预测、解释或迁移问题。

## 情境检查

- “用一次一问带我学斜率，文字像 80% STE”：保持自然中文短句，先画当前关系，不自动制作视频或改成英文。
- “做 HTML 实验让我拖动割线”：直接创建单文件实验，保持一个当前问题，检验边界值、重置和键盘操作。
- “用本地资源做一个 3b1b 风格的导数解释视频”：检查现有渲染/TTS 能力，创作原创图形与旁白，渲染并验收；不能只给一个网页就声称成片完成。
- “做完视频直接给我，不要测试我”：交付视频、字幕与文字稿，不强制追问。
