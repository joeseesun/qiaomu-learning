# Teaching Clarity

这份参考用于主题很大、学习者基础未知、或模型准备从直觉跳到符号时。目标不是多讲，而是让学习者看见每一步之间的连接。

## 1. 固定教学顺序

默认按以下顺序推进：

```text
具体例子 → 可见关系 → 口头规则 → 数学符号 → 形式化定义
```

- **具体例子**：从一个熟悉动作、两个小数字或同一个生活场景开始。
- **可见关系**：用坐标草图、ASCII、表格、时间线或一张问题承载型图展示正在变化的量。
- **口头规则**：用一句白话说清“哪个量改变，会让哪个量怎样改变”。
- **数学符号**：只引入当前一步需要的符号；第一次出现时立刻定义，并沿用同一个例子。
- **形式化定义**：等学习者能从例子说出关系后，再引入极限、导数、积分等严格表述。

如果学习者只答对了一个算术结果，先做“结果 → 意义”的连接，不要直接把难度提升到新符号。

## 2. 清晰回合模板

活跃回合可以按这个短模板组织；不必每次完整显示标签：

```text
具体反馈：你已经抓住了 <上一答复中正确的关系>。
当前台阶：这一步只看 <一个可观察关系>。
搭架：<一个同例子的数字、图、表或短解释>。
唯一问题：<让学习者完成当前这一步的一个动作>？
```

每回合最多引入一个新变量或术语。若必须使用新符号，先写“这里的 `h` 只是很短的一段时间”，再让学习者在同一例子里观察它的作用。

避免以下跳步：

```text
平均速度 → 直接写极限公式
曲线 → 直接写导数记号
面积 → 直接写积分号
```

中间至少补一个可见关系和一个口头解释。

## 3. 微积分的默认视觉锚点

当当前台阶属于下列主题时，主动建立视觉锚点，不必等学习者先说“太抽象”：

| 主题 | 优先展示的结构 | 第一观察问题的类型 |
|---|---|---|
| 平均速度 / 瞬时速度 | 时间—位置表、割线逐渐变窄 | 哪个时间段更短？ |
| 斜率 / 导数 | 曲线上两点连线逐渐贴近切线 | 哪条线更贴近曲线在该点的方向？ |
| 极限 | 数轴上从左右靠近一个点 | 数值从哪一侧靠近？ |
| 积分 / 累积量 | 曲线下的矩形逐渐变窄 | 哪些矩形共同覆盖了哪一块区域？ |
| 变化率 | 两个量的坐标关系或时间线 | 一个量增加时，另一个量怎样变？ |

精确数值和坐标优先用确定性图示或文字图示。若曲线形状、运动过程或三维关系需要更强直觉，且内置生图已获授权，可调用一张教学图；图中只保留当前问题需要的元素，不写答案。

## 4. “配图”不等于“每轮生图”

视觉节奏按当前认知台阶判断：

1. 首次进入可视化的微积分台阶：给一个视觉锚点；可用 ASCII、表格或确定性草图时，不必为了装饰调用生图。
2. 图后先问一个观察问题，让学习者说出图中关系。
3. 学习者完成观察后，才进入口头规则或符号；下一回合重新判断是否仍需要图。
4. 如果学习者说“太抽象”“不理解”或明确求图，立即切换当前台阶的模态；不要继续改写原来的抽象解释。

文字替代必须能独立承载同一个观察任务。例如：

```text
图示：一条位置—时间曲线，以及同一点附近一条较长割线和一条更短割线。
文字替代：两条线都连接曲线上的两点，但第二条线的两个端点更接近。
问题：哪条线更能反映曲线在这个点附近的方向？
```

上例只检查“观察哪条线更贴近”，不同时要求命名导数或解释极限。

## 5. 用户反馈后的修复动作

- **“听不懂 / 太抽象”**：先给确定性图示或文字图示，再把问题降到一个可见差异。
- **只给数字、不说意义**：保留数字正确处，追问它在当前情境中代表什么；暂不升级符号。
- **符号混乱**：退回同一个数字例子，逐个解释变量，暂时去掉形式化记号。
- **连续两次卡住**：改用边界对比或具名人物情境；仍卡住才给 2–4 句微解释，再让学习者重建一步。
- **要求直接讲**：退出苏格拉底模式，直接解释，不用继续追问来“验证学习”。

## 6. 质量检查

发送前检查：

- 学习者能否只根据本回合内容知道“现在要观察什么”？
- 新符号是否已经用白话定义并连接到同一个例子？
- 视觉材料是否比文字多提供了一个结构关系，而不是重复装饰？
- 最后一行是否只有一个、且足够小的学习问题？
